# 形象包规范（Character Pack）

本仓库自带一个占位形象 `assets/characters/placeholder/`，`git clone` 后即可直接运行。
想让桌宠换成自己的形象，按本文档做一份形象包，放进角色目录即可——**切换全程无需重启进程**。

## 1. 目录结构

```
<角色 id>/
└── videos/
    ├── manifest.json          # 形象元数据（可选，但强烈建议）
    ├── idle/                  # 待机（循环播放，必需）
    ├── turn/                  # 转向 / 东张西望（可选）
    ├── move/                  # 移动（可选，配合 move_strides.json 调位移）
    ├── click/                 # 点击回应（可选）
    ├── drag/                  # 被拖拽反馈（可选）
    └── random/                # 随机小动作（可选）
```

- `<角色 id>` 即角色名，会显示在右键菜单「切换角色」里；建议用小写字母、数字、`-`、`_`。
- `idle` 是唯一必需的目录，缺了它该角色无法上场。
- 旧结构 `idle_turn/`（待机+转向合并目录）仍兼容。

## 2. manifest.json

```json
{
  "name": "显示名（可带中文）",
  "body_box": [170, 60, 470, 330],
  "head_box": [228, 55, 412, 215],
  "license": "素材许可说明",
  "note": "任意备注"
}
```

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `name` | 否 | 菜单里显示的名字，缺省用角色 id |
| `body_box` | 否 | 身体框 `[x1, y1, x2, y2]`，用于命中判定与缩放锚点 |
| `head_box` | 否 | 头部框，用于屏幕边缘探头/说话锚点；缺省按身体框高度 45% 从顶部截取 |
| `license` | 否 | 素材许可，开源仓库里请如实填写 |
| `note` | 否 | 备注，不做解析 |

## 3. 视频规格

| 项目 | 要求 |
| --- | --- |
| 容器 / 编码 | WebM（VP9），alpha 通道保留 |
| 画布 | 640 × 360（`CANVAS_W` × `CANVAS_H`） |
| 脚底基线 | y = 330（`FEET_Y`），下方 30px 留给阴影与padding |
| 帧间隔 | 42 ms（约 24 fps，`FRAME_MS`） |
| 单段时长 | 建议 2–6 秒，循环动作首尾要能接上 |
| 音轨 | 不需要（音效走 `assets/sounds/`，与形象解耦） |

同一目录下可以放多段视频，运行时会随机挑选该动作的片段；文件名随意，但建议带语义前缀
（如 `idle_float.webm`、`click_happy.webm`）。

## 4. 可调参数

- `videos/move_strides.json`：按动画文件名逐条覆盖「每圈地面位移（px）」，用于让走路动画与
  实际位移对齐。缺省值 120px（`MOVE_STRIDE_DEFAULT_PX`），移动距离在 60–240px 之间随机。
- `no_mirror`：某些动作（如带文字的动画）不适合水平镜像时，在 manifest 或资源目录中声明后
  该动作不再镜像播放。

## 5. 一键切换

| 入口 | 行为 |
| --- | --- |
| 右键菜单「切换角色」 | 缩略图行，点一下即换（首帧缩略图自动生成并缓存） |
| 热键「下一个形象」 | `cycle_character`，按角色列表顺序循环 |
| 定时轮番 | 设置里开启后按间隔自动轮换 |

切换走同一条 `switch_character` 路径：换库、持久化、聊天面同步、缩略图缓存作废都在这里收口，
**不重启进程、不重启 ffmpeg 长连接**。

## 6. 放置位置（扩展形象）

除内置的 `assets/characters/`，还支持运行时外挂目录（按优先级）：

1. 程序（或源码根目录）同级的 `characters/`
2. 打包变体的数据目录下的 `characters/`（如 `%APPDATA%/dsh-pet-standalone-webm-chat/characters/`）
3. 旧版目录 `dsh-pet-standalone/characters/`（兼容老用户）

把整个 `<角色 id>/` 目录丢进去即可，重启后在菜单里出现。

## 7. 许可与合规（重要）

- 本仓库自带的 `placeholder` 形象为本项目程序化绘制的原创占位素材，**CC0-1.0**，可自由使用、修改、再分发。
- 请勿把自己无权再分发的素材（第三方同人角色、他人约稿、影视截图等）提交到本仓库或随包分发。
  自己本机用没问题，但 PR 里带上就是侵权。
- 形象包命名不要暗示与任何厂商/品牌有关联（如直接叫 `chatgpt`、`claude` 并配官方 logo），
  以免构成商标误用。
